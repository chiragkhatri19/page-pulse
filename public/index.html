URL audit service · v1

Take the vitals of any public page.

One request in, one scored report out. Page Pulse fetches a URL under strict timeouts, reads its markup and response headers, and grades it across SEO, accessibility, performance and security. Repeat audits inside the cache window come back without touching the origin.

Run an audit

Enter any public http or https URL. Private and loopback addresses are rejected before a socket opens.

    # Audit a URL

  -H 'content-type: application/json' \

# Same thing, GET, bypassing the cache
curl 'https://page-pulse.onrender.com/v1/audit?url=example.com&fresh=true'
    EndpointPurpose
    POST /v1/auditAudit a URL. Body: url, optional fresh, optional ttlSeconds.
    GET /v1/auditSame audit via query string, for links and browsers.
    GET /v1/statsCache hit rate, in-flight audits, queue depth, tracked rate-limit clients.
    GET /healthzLiveness. Never rate limited.
    GET /readyzReadiness. Returns 503 once the work queue is saturated.
